# B站直播海外观看助手

用于解决海外访问部分 Bilibili 直播间时出现 **“非常抱歉，当前直播间暂时无法显示”** 的问题。

适用于 Windows 上的 Chrome、Edge 等 Chromium 浏览器，要求 Chromium 111 或更新版本。Firefox、手机端暂未适配。

## 下载与安装

1. 打开 **[最新版 Release](https://github.com/zYuanXiao/bili-live-player-helper/releases/latest)**，在 Assets 中下载 `bili-live-player-helper-v版本号.zip`，解压到准备长期保留的文件夹。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 地址栏输入 `edge://extensions`。
3. 打开 **开发者模式**，点击 **加载已解压的扩展程序**。Edge 部分版本显示为“加载解压缩的扩展”。
4. 选择解压后直接包含 **`manifest.json`** 和 **`安装说明.txt`** 的文件夹。
5. 在浏览器扩展菜单中，将“B站直播播放器助手”固定到工具栏，方便手动操作。
6. **刷新已经打开的直播间一次。**

如果使用 **Code → Download ZIP** 下载源码，请选择解压后里面的 **`extension` 文件夹**。

安装无需 Node.js、Python、代理或额外服务器。ZIP 解压完成后可以删除；**浏览器加载的文件夹需要保留，不能删除或移动**。

## 日常使用

正常打开 `https://live.bilibili.com/直播间号` 即可使用。

| 功能 | 操作与行为 |
| --- | --- |
| 自动切换 | 默认开启。发现受限提示后查询公开房间状态；确认正在直播，且未隐藏、未锁定、未加密时尝试切换。 |
| 手动切换 | 点击页面左下角“切换播放器”，或工具栏插件里的“切换到备用播放器”。关闭自动功能时也能手动使用。 |
| 恢复原播放器 | 点击“恢复原播放器”。当前标签页的这个房间会暂停自动切换，刷新后也会保留该选择。换房间或重新开启自动开关后恢复自动行为。 |
| 收起面板 | 点击左下角面板右侧的箭头，收起说明和设置。 |
| 重新载入 | 备用播放器加载失败时，点击“重新载入”重新打开官方入口。 |
| 独立打开 | 在新标签页打开该房间的官方活动播放器，原网页保留。 |
| 播放诊断 | 点击工具栏插件，展开“播放诊断”，查看缓冲秒数、视频就绪级别和掉帧数据。 |

如果浏览器阻止自动播放，请点击视频中的播放按钮。默认静音时可在视频中开启声音。

切换成功后，插件会隐藏识别出的原直播间限制提示层；恢复原播放器时还原原有样式。插件只保留原网页已经加载的区域，不会重新实现未加载出来的聊天或其他 B站功能。

## 画质、线路和全屏

把鼠标移到视频上，使用 **视频右下角的官方菜单** 切换画质、线路、音量或全屏。“独立打开”同样保留官方画质菜单。

画质档位来自该直播间实际提供的视频流。**如果房间只有原画，插件不能凭空添加 720P、480P 等低码率档位。** 显示的“实际画面 宽 × 高”用于观察当前解码尺寸；相同尺寸的视频流也可能具有不同码率。

## 更新方法

1. 将新版文件覆盖到原来加载的插件文件夹；使用源码时更新 `extension` 内的文件。
2. 到 `chrome://extensions` 或 `edge://extensions`，点击本插件的 **重新加载**。
3. **刷新直播间。** 旧页面中的脚本不会仅因文件已替换而自动退出。

如果重复安装了多个版本，请只启用一个版本。

## 常见问题

### 没有按钮，或提示页面未连接

刷新直播间；确认插件已经启用，且浏览器允许它在 B站运行。确认加载的是直接包含 `manifest.json` 的文件夹。

### 没有自动切换

确认“受限时自动切换”已经开启。如果之前点过“恢复原播放器”，当前房间会暂停自动切换；重新开启自动开关即可解除，也可以直接手动切换。

主播下播、轮播、房间隐藏、锁定或加密不会自动按地区限制处理。自动识别依赖页面结构；页面改版后可能需要更新插件。

### 有画面，但“非常抱歉”的白框还在

确认已经切换到备用播放器，再重新加载插件并刷新页面。插件会处理已知的直播间限制弹层；如果 B站改变了该层的结构，请通过 Issue 描述问题。

### 声音和画面一起停住，或者转圈

尝试视频菜单中的其他可用线路；有较低画质时可降低画质。也可以使用“独立打开”对照，或点击“重新载入”。

卡顿后重新打开工具栏插件，展开“播放诊断”。缓冲接近 0 且持续转圈通常需要排查线路或带宽；掉帧较多则可能涉及解码和设备负载。诊断数据仅用于辅助判断。

插件减少了整页扫描和重复样式更新；原播放器提供匹配接口时会停止原流，恢复时重新载入。未知播放器版本可能只能暂停原视频，无法保证其后台取流也停止。

### 备用播放器也无法播放

尝试“独立打开”确认。如果官方备用入口本身也受到限制，此插件无法保证解决。不要把主播下播或房间锁定误认为插件故障。

### 如何停用或卸载

在扩展管理页关闭或移除插件，然后刷新直播间。仅停用扩展不会立刻清理已经注入旧页面的脚本。

## 权限与数据

- 扩展权限只有 `storage`，用于保存自动切换设置与当前浏览器会话的逐标签页选择。
- 访问范围为 `live.bilibili.com`、`api.live.bilibili.com` 和官方活动播放器所在的 `www.bilibili.com`。浏览器的主机授权可能按整个域名显示，即使声明的路径较窄。
- 插件向公开的 `room_init` 接口查询房间状态，该请求省略登录凭据。
- 插件代码不读取 Cookie，不上传播放诊断，也不保存完整的签名播放地址。诊断只保留在当前页面内存中。
- 官方播放器本身仍按 B站规则使用网络和浏览器登录状态。
- 插件不修改 DNS、系统代理、VPN、网卡、路由或 Windows 服务。

## 项目结构

```text
extension/
  manifest.json          扩展配置和权限
  background.js          房间状态查询、会话存储和消息转发
  core.js                地址解析、限制识别、播放器地址和诊断格式
  content.js             页面面板、播放器切换和状态上报
  page-media-bridge.js   原播放器的暂停、断流和恢复
  popup.html/css/js      工具栏弹窗
  icons/                 扩展图标
scripts/
  check.cjs              语法、权限和资源检查
  package.py             生成可分发的插件 ZIP
.github/workflows/
  release.yml            检查、打包和发布 Release
README.md
package.json
```

运行时没有第三方依赖，无需编译。仓库不包含测试代码、测试截图或本机调试记录。

维护者可使用 Node.js 18+ 执行 `npm run check`；使用 Python 3.10+ 执行 `python scripts/package.py`。打包只收录固定清单中的12个运行文件和中文安装说明，生成的 ZIP 与 SHA-256 校验文件位于 `dist/`，不会提交到源码仓库。

推送到 `main` 后，Release 工作流会检查版本、打包，并发布对应版本的 ZIP 和校验文件；也可在 Actions 中手动运行。已经正式发布的同版本不会被覆盖。更新代码准备发布时，需要同时更新 `extension/manifest.json` 和 `package.json` 的版本号。

## 反馈问题

提交 Issue 时请说明浏览器版本、插件版本、直播间号、操作步骤和可见错误。卡顿问题可附缓冲秒数及掉帧比例。

请勿提交 Cookie、密码、账号令牌或完整的带签名播放地址。
